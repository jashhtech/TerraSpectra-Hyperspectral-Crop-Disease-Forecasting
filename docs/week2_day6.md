# TerraSpectra – Week 2 Day 6

**Role:** ML Model & Inference Engineer  
**Task:** Baseline CNN vs 3D-CNN Model Comparison

## 1. Objective

The objective of Day 6 is to compare the performance of the baseline CNN and 3D-CNN models using common evaluation metrics.

## 2. Work Completed

- Created `src/compare_models.py`.
- Implemented loading of trained model checkpoints.
- Prepared a common test dataset for both models.
- Calculated accuracy, precision, recall, and F1-score.
- Measured model inference time.
- Generated a model comparison report.
- Saved comparison results in CSV format.

## 3. Evaluation Metrics

| Metric | Purpose |
|---|---|
| Accuracy | Measures overall prediction correctness |
| Precision | Measures correctness of positive predictions |
| Recall | Measures identification of actual positive samples |
| F1-score | Combines precision and recall |
| Inference Time | Measures prediction execution time |

## 4. Expected Outcome

The comparison helps understand the differences between the baseline CNN and 3D-CNN architectures.

## 5. Limitations

The comparison requires successfully trained checkpoints and a separate test dataset. Actual metric values must be added after running the evaluation.
