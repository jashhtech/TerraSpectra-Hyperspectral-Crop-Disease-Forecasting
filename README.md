# TerraSpectra

Hyperspectral Crop Disease Forecasting.

## Project Overview

TerraSpectra uses hyperspectral imagery
and machine learning for crop disease forecasting.

## Technologies

- Python
- FastAPI
- React
- Deck.gl
- MapLibre
- Axios

## Backend Setup

cd backend

pip install -r requirements.txt

uvicorn app.main:app --reload

## Frontend Setup

cd frontend

npm install

npm run dev

## Features

- API health monitoring
- React dashboard
- GIS map visualization
- Sample disease overlay
- Frontend API integration
