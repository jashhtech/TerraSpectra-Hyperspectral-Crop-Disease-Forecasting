
# TerraSpectra Dataset

## Project
Hyperspectral Crop Disease Forecasting

## Purpose
The dataset is used to develop a machine
learning model for crop health classification.

## Input Data
- Hyperspectral image cubes
- Multiple spectral bands
- Spatial information
- Crop labels

## Model Input Format
Batch x Channels x Height x Width

Example:
1 x 200 x 64 x 64

## Prediction Target
Provisional classes:
0 - Healthy
1 - Diseased

Actual class definitions must be confirmed
with the project team.

## Dataset Requirements
- Image cubes and labels must match.
- Input values should be numerical.
- Missing and invalid values must be checked.
- Training and validation data must be separated.

## Note
Actual dataset format and class labels will
be finalized after receiving team data.
